# برنامه‌ریز من — ساخت APK با سرویس ابری (بدون نصب هیچ‌چیزی)

با این روش، APK کاملاً روی سرورهای گیت‌هاب ساخته می‌شه (رایگان) و تو فقط با مرورگر کار می‌کنی — نه Android Studio لازمه، نه Node.js، نه هیچ نصب دیگه‌ای روی سیستم خودت.

من یک فایل تنظیمات (`.github/workflows/build-apk.yml`) داخل پروژه گذاشتم که به گیت‌هاب می‌گه: «هر وقت این فایل‌ها آپلود شدن، خودت پروژه رو بساز و APK رو تحویل بده».

---

## مرحله ۱ — ساخت حساب گیت‌هاب (رایگان، ۲ دقیقه)
اگه حساب نداری، به آدرس زیر برو و ثبت‌نام کن:
https://github.com/signup

## مرحله ۲ — ساخت یک ریپازیتوری جدید
1. بعد از ورود، روی علامت **+** بالای صفحه بزن → **New repository**
2. یک اسم بذار، مثلاً `my-reminder-app`
3. می‌تونی **Private** رو انتخاب کنی (فقط خودت ببینیش)
4. روی **Create repository** بزن

## مرحله ۳ — آپلود فایل‌های پروژه
1. تو صفحهٔ ریپازیتوری تازه‌ساخته‌شده، روی لینک **uploading an existing file** بزن (یا از منوی **Add file → Upload files**)
2. فایل زیپی که بهت دادم رو از حالت فشرده خارج کن (Extract/Unzip) روی کامپیوترت
3. **همهٔ فایل‌ها و پوشه‌ها رو با هم** (شامل پوشهٔ مخفی `.github`) بکش و داخل کادر آپلود گیت‌هاب رها کن

   ⚠️ نکتهٔ مهم: پوشهٔ `.github` چون با نقطه شروع می‌شه ممکنه در حالت عادی مخفی باشه. مطمئن شو که فایل‌های مخفی سیستم‌عاملت رو نشون بده (در ویندوز: تنظیمات File Explorer → Show hidden items؛ در مک: کلید ⌘+Shift+.) تا مطمئن بشی پوشهٔ `.github/workflows/build-apk.yml` هم آپلود می‌شه. اگه گیت‌هاب بهت اجازهٔ کشیدن کل پوشه رو نداد، می‌تونی مسیر `.github/workflows/build-apk.yml` رو داخل ریپو با دکمهٔ «Add file → Create new file» بسازی و محتوای همون فایل رو داخلش پیست کنی.

4. پایین صفحه روی **Commit changes** بزن

## مرحله ۴ — دیدن ساخته‌شدن APK
1. به تب **Actions** بالای صفحهٔ ریپازیتوری برو
2. یک اجرای در حال انجام (workflow run) به اسم «Build Android APK» می‌بینی — چند دقیقه صبر کن تا تیک سبز بخوره (حدود ۳ تا ۶ دقیقه طول می‌کشه)
3. روی همون اجرای تمام‌شده کلیک کن
4. پایین صفحه، بخش **Artifacts** رو ببین — یک فایل به اسم `reminder-app-apk` هست، روش کلیک کن تا دانلود بشه (یک فایل zip که خودِ APK داخلشه)

## مرحله ۵ — نصب روی گوشی
1. فایل zip دانلود‌شده رو باز کن، فایل `app-debug.apk` داخلشه
2. این فایل رو به گوشی اندرویدت منتقل کن (تلگرام به خودت، گوگل‌درایو، کابل و...)
3. روی گوشی بازش کن و نصب کن؛ اگه هشدار «نصب از منابع ناشناس» اومد، اجازه‌ش رو بده (طبیعیه چون از گوگل‌پلی نیومده)

---

## یک تنظیم مهم بعد از نصب، برای این‌که نوتیف‌ها همیشه به‌موقع برسن
1. تنظیمات گوشی → اپ‌ها → **برنامه‌ریز من**
2. مجوزها → **زنگ هشدار و یادآوری‌ها (Alarms & reminders)** → فعال کن
3. بهینه‌سازی باتری → برای این اپ گزینهٔ **بدون محدودیت (Unrestricted)** رو انتخاب کن

بدون این تنظیم، بعضی گوشی‌ها (مخصوصاً سامسونگ، شیائومی، هواوی) نوتیف اپ‌های خارج از گوگل‌پلی رو با تأخیر یا اصلاً نمی‌دن — این محدودیت خود اندرویده.

---

## اگه بعداً چیزی رو عوض کردی (مثلاً رنگ یا متن اپ)
کافیه فایل تغییریافته (مثلاً `www/index.html`) رو دوباره آپلود کنی و Commit کنی؛ گیت‌هاب خودکار دوباره build می‌گیره و APK جدید تو تب Actions آماده می‌شه — نیازی به تکرار کل مراحل نیست.

## اگه خواستی به‌جای GitHub Actions از سرویس دیگه‌ای استفاده کنی
گزینهٔ دیگه‌ای که مخصوص همین کاره: **Ionic Appflow** (appflow.ionic.io) — سرویس رسمی برای build ابری پروژه‌های Capacitor، یک نسخهٔ رایگان محدود داره و رابط کاربری ساده‌تری برای غیربرنامه‌نویس‌ها ارائه می‌ده، ولی نیاز به اتصال ریپازیتوری گیت‌هاب داره (پس مرحلهٔ ۱ تا ۳ بالا رو باز هم لازم داری).
